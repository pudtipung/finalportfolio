# Personal Portfolio | พุฒิพงศ์ มูลชารี (ม่อน)

เว็บไซต์พอร์ตโฟลิโอส่วนตัว ดีไซน์ทันสมัยด้วย Tailwind CSS & Deep Blue Dark Theme พร้อมระบบสลับหน้าแบบ Single Page Application (SPA) และอนิเมชันการโหลดที่สมูท

## ✨ ฟีเจอร์หลัก (Features)
- **Deep Blue & Neon Cyan Dark Theme**: ดีไซน์โทนสีน้ำเงินเข้มและฟ้าไซแอนเรืองแสง ทันสมัย สบายตา
- **Smooth Page Transitions**: ระบบโหลดเปลี่ยนหน้านุ่มนวล พร้อมแถบความคืบหน้าด้านบนและ Overlay หมุนสวยงาม
- **หมวดหมู่เนื้อหาครบครัน**:
  - 🏠 **หน้าแรก (Home)**: แนะนำตัว ประสบการณ์ และทักษะหลัก
  - 🎓 **ประวัติการศึกษา (Education)**: ไทม์ไลน์การศึกษาทุกระดับ
  - 💼 **ผลงาน (Portfolio)**: ผลงานโปรเจกต์พร้อมระบบกรองหมวดหมู่
  - 🏆 **กิจกรรม (Activity)**: แกลเลอรีรูปภาพกิจกรรมและการอบรม
  - 📬 **ติดต่อ (Contact)**: ช่องทางการติดต่อและฟอร์มส่งข้อความ
- **Responsive Web Design**: รองรับการแสดงผลทุกหน้าจอ ไม่ว่าจะเป็นมือถือ แท็บเล็ต หรือคอมพิวเตอร์
